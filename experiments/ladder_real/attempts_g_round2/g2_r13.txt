# 동기 처리 vs 비동기 처리

## 동기 처리 (Synchronous)

**언제 사용하나요:**
- 작업이 순서대로 진행되어야 할 때 (예: A 작업 완료 후 B 작업)
- 작업 시간이 매우 짧을 때 (밀리초 단위)
- 결과를 즉시 반환받아야 할 때
- 코드가 간단하고 순차적 흐름이 명확할 때
- 단순한 계산이나 데이터 처리

**예시:**
```javascript
const result = calculateSum(5, 10);  // 결과가 바로 나옴
console.log(result);  // 10을 바로 출력
```

## 비동기 처리 (Asynchronous)

**언제 사용하나요:**
- 오래 걸리는 작업을 할 때 (네트워크 요청, 파일 I/O, DB 쿼리)
- UI가 멈추면 안 될 때
- 여러 작업을 동시에 진행할 때
- 사용자 응답성이 중요할 때
- 콜백, Promise, async/await로 처리

**예시:**
```javascript
// 네트워크 요청 - 시간이 걸림
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));  // 응답 올 때까지 기다림
```

## 실전 판단 기준

| 상황 | 사용 처리 |
|------|---------|
| API 호출, HTTP 요청 | 비동기 |
| 데이터베이스 쿼리 | 비동기 |
| 파일 읽기/쓰기 | 비동기 |
| 타이머/지연 작업 | 비동기 |
| 간단한 계산 | 동기 |
| 변수 할당 | 동기 |
| 웹 서버 응답 | 비동기 |
| 유저 입력 처리 | 비동기 |

**핵심:** 시간이 걸리는 I/O 작업은 무조건 비동기로 해야 프로그램이 응답성 있게 동작합니다.
