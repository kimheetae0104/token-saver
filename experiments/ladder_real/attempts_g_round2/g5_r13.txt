# 버그 수정 우선순위

**수정 순서: (1) → (3) → (2)**

## 이유

### 1순위: 로그인 실패시 500에러 + 스택트레이스 노출 (보안)
- **가장 긴급하게 수정해야 함**
- 스택트레이스 노출은 **보안 취약점**. 공격자가 시스템 아키텍처, 파일 경로, 라이브러리 버전 등 민감한 정보를 노출받음
- 사용자 데이터 침탈, 시스템 공격으로 발전할 수 있음
- 즉시 에러 핸들링을 추가해서 사용자에게 일반적인 메시지만 보이도록 수정 필요

### 2순위: 결제 완료 후 이메일 알림 20초 지연 (기능/비즈니스)
- **비즈니스 영향이 큼**
- 결제는 핵심 기능이고, 사용자는 결제 완료 확인을 빨리 받고 싶어함
- 20초 지연되면 사용자가 결제 실패했다고 착각해서 재결제하거나 결제 취소 요청할 가능성 높음
- 데이터 무결성이나 보안은 아니지만, 수익/고객 만족도 직결

### 3순위: 다크모드에서 버튼 위치 어긋남 (UI/스타일)
- **기능에 영향 없음**
- 일부 사용자만 영향 (다크모드 사용자)
- 버튼을 클릭할 수 있으므로 사용성 자체는 문제 없음
- CSS/레이아웃 미세 조정이라 상대적으로 빠르게 수정 가능

---

**핵심 원칙**: 보안 > 비즈니스 영향 > UI/UX 미세 문제
