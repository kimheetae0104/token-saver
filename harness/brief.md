# 테스트 시나리오 brief — 미니 쇼핑몰 (정적 프론트 3페이지)

브랜드: "무명(MUMYUNG)" — 미니멀 라이프스타일 편집샵. 톤: 차분·절제·따뜻한 뉴트럴.

## 페이지 3개
1. **landing.html** — 히어로(브랜드 문구+CTA), 특징 3블록, 큐레이션 상품 그리드(4개), 푸터.
2. **products.html** — 상단 필터바(카테고리 칩), 상품 카드 그리드(8개: 이미지자리·이름·가격·담기 버튼), 페이지네이션.
3. **signup.html** — 회원가입 폼(이메일·비밀번호·비밀번호확인·약관 체크·가입 버튼), 로그인 링크.

## 공통 요구 (audit.mjs 게이트 통과 조건과 직결)
- 순수 정적 HTML + inline CSS(자기완결, 외부 의존 0, JS 최소).
- `<meta name="viewport" content="width=device-width,initial-scale=1">` 필수, `<html lang="ko">`.
- 대비 WCAG AA(본문 4.5:1), 터치타깃 ≥24×24px, 인터랙티브 요소 `cursor:pointer`.
- 디자인토큰(팔레트·타입스케일·간격·라운드)은 아키텍트가 정하고 3페이지가 일관 사용.
- 반응형(폭 390 모바일에서 깨지지 않게).
